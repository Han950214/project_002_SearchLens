# Chrome Web Store 商店文案（zh-CN）

## 推荐标题

SearchLens CN

## 简短说明

在百度网页搜索结果页本地提供可信度参考、推荐排序与域名偏好控制。

## 详细说明

SearchLens CN 是独立的搜索结果可信度与推荐辅助工具。它在百度网页搜索结果页读取当前公开结果，在设备本地进行启发式分析，并以可关闭的独立面板提供辅助排序、可信度参考和原因说明。百度原始结果保持可用。

核心功能：

- 按当前搜索词和公开结果信号生成辅助推荐顺序；
- 展示可信度参考、主要原因、来源域名和原始排名；
- 识别页面中可见的推广与第三方下载站信号，并提示用户继续核对来源；
- 允许用户提升、降低或隐藏域名，偏好只保存在当前浏览器；
- 在设置页控制推荐数量、可信度、理由和下载站提示。

所有分析在本地完成。SearchLens CN 不上传搜索词、搜索结果、浏览记录、点击记录或域名偏好；不使用 AI、云端排序、analytics、广告或远程代码。

SearchLens CN 不是百度或其他第三方的官方产品，不代表授权、合作、认证或背书。可信度与推荐仅用于辅助判断，不构成安全检测、杀毒、认证或绝对可信承诺。请继续核对原始搜索结果、真实域名和下载来源。

## 单一用途

在百度网页搜索结果页本地分析公开搜索结果，并提供辅助性的可信度参考、推荐排序和用户偏好控制。

## 权限说明

- `storage`：在当前浏览器保存显示设置和用户主动配置的域名偏好。
- 百度网页搜索结果页访问范围：仅在 `baidu.com/s*` 与 `www.baidu.com/s*` 读取当前公开结果并显示面板。

扩展不申请额外 `host_permissions`，不申请 `tabs`、`history`、`cookies`、`webRequest`、`downloads`、`identity`、`management` 或 `<all_urls>`。

## 隐私摘要

页面搜索词和结果仅在当前设备内存中处理，不持久化；设置和域名偏好存储在 `chrome.storage.local`。无远程服务器、数据出售、第三方共享、统计上传或人工读取。
