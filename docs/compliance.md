# 商业化与合规边界

SearchLens 是独立的搜索结果可信度辅助工具，不是百度、微信、腾讯或 Google 的官方产品，也不代表其立场或授权。

## 品牌与内容

- 不使用未经授权的第三方 Logo、图标、截图或品牌素材。
- 除非取得真实授权，不使用“官方授权”“官方认证”“百度官方”“微信官方”等可能误导用户的表述。
- 不复制竞品的源码、UI、文案、规则库或商业数据库。

## 数据与隐私

- 默认在本地处理搜索结果，不上传、不出售用户搜索词、浏览记录或点击记录。
- 当前设置和域名偏好仅写入 `chrome.storage.local`，不提供账号、云同步或统计上传。
- 未来如增加云同步、账号、统计或反馈上传，必须先补充隐私说明、取得用户同意，并采用最小权限设计。

## v0.3 产品表述

- 使用“可信度辅助判断”“建议核对”“第三方下载站谨慎”等有限表述，不承诺“绝对安全”。
- 面板保持独立的 SearchLens 品牌与视觉，不模仿或冒充百度原生功能。
- 官网、可信、下载站、推广和百度系标签来自本地启发式规则及页面信号，不代表第三方认证。
- 本地规则仅维护实现所需的小型启发式集合，不复制第三方商业规则库或数据库。

## 发布前检查

- 检查开源依赖的 license 与分发义务。
- 审核 Chrome Web Store 文案、截图、图标和隐私政策，避免误导性品牌或功能描述。
- 如后续增加云同步、账号、反馈上传或远端分析，发布前补充用户同意流程和最小权限设计。
